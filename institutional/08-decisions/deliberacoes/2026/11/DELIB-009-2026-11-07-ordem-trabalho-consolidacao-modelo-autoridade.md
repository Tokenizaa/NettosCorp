# ORDEM DE TRABALHO — Consolidação do Modelo de Autoridade v1.2

**Responsável:** Hermes — Chefe de Gabinete Executivo\
**Autoridade solicitante:** Fundador — Netto Farias\
**Orientação estratégica:** Conselheiro

## Objetivo

Consolidar as deliberações sobre autoridade executiva e arquitetura organizacional da NettosCorp, atualizando a documentação institucional para a versão 1.2.

## Instruções

### 1. Atualizar o modelo de autoridade

Arquivo:\
`empresa/00-governance/MODELO_AUTORIDADE_DIRECAO_EXECUTIVA.md`

Incorporar:

- Fundador: autoridade executiva humana e legal.
- Conselheiro: assessoria estratégica.
- Hermes: Chefe de Gabinete Executivo, reportando diretamente ao fundador.
- Orquestrador Global: subordinação administrativa a Hermes, com autoridade operacional delegada e limitada.
- Diretor Executivo de Operações: não será criado nesta etapa.
- Diretores especializados: respondem institucionalmente ao fundador; Hermes coordena integração e acompanhamento executivo.

### 2. Definir os limites do Orquestrador Global

Documentar expressamente:

- Distribuição e coordenação de tarefas.
- Acompanhamento de execuções.
- Monitoramento de dependências.
- Solicitação de atualizações e relatórios.
- Comunicação com supervisores locais.
- Ausência de autoridade estratégica, executiva ou disciplinar.
- Preservação da autonomia dos supervisores locais.

### 3. Atualizar a proposta de equipe

Arquivo:\
`empresa/02-organization/proposta-equipe/PROPOSTA_EQUIPE.md`

Atualizar para versão 1.2, mantendo os seis especialistas prioritários:

1. Software Architect.
2. Backend Architect.
3. Frontend Developer.
4. DevOps Automator.
5. Project Manager Senior.
6. Technical Writer.

Não implantar os agentes ainda.

### 4. Registrar as relações organizacionais

Documentar a diferença entre:

- Hierarquia administrativa.
- Autoridade funcional.
- Delegação operacional.
- Supervisão local de projetos.

Considerar as limitações do Paperclip, especialmente o campo `reports_to`, sem alterar seu código ou criar extensões.

### 5. Atualizar índices

Atualizar os índices e referências documentais afetados, preservando a estrutura institucional existente.

## Restrições

- Não instalar ferramentas.
- Não criar agentes no Paperclip.
- Não alterar projetos ou repositórios de software.
- Não definir orçamentos ou adaptadores.
- Não iniciar implantação departamental.
- Não alterar decisões que não estejam expressamente autorizadas nesta ordem.

## Critérios de conclusão

Apresentar:

1. Documentos atualizados e respectivas versões.
2. Resumo das alterações.
3. Confirmação de consistência entre os documentos.
4. Decisões que ainda dependem do fundador.
5. Próxima etapa recomendada, sem executá-la.

A conclusão desta ordem consolida a arquitetura de autoridade, mas não representa autorização automática para implantação da equipe.

## 4. Próxima etapa após a conclusão

Depois da entrega de Hermes, deliberaremos sobre a estrutura departamental da NettosCorp, definindo:

- Departamentos necessários.
- Missão e responsabilidades de cada departamento.
- Relações entre diretorias e departamentos.
- Posições de liderança.
- Integração dos seis especialistas.

Somente depois disso avançaremos para a configuração dos agentes no Paperclip.

Deliberação final: Hermes está autorizado a executar a ordem acima. A implantação dos agentes continua pendente de nova autorização do fundador.
