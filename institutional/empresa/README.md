# NettosCorp — Documentação Institucional

Este diretório é o repositorio institucional da NettosCorp, empresa de desenvolvimento de software em fase de fundacao e estruturacao.

Toda atividade relevante da NettosCorp devera ser documentada, versionada, rastreavel e verificavel. Nenhum agente deve depender exclusivamente da memoria de uma conversa para conhecer suas responsabilidades ou as decisoes da empresa.

## Hierarquia e reportacao

- Fundador: Netto Farias (autoridade executiva humana, decisao final)
- Conselheiro: parceiro estrategico de IA
- Hermes: Chefe de Gabinete Executivo, reporta diretamente ao fundador

Nenhum codigo de projeto deve ser alterado e nenhuma estrutura do organograma deve ser implantada antes do alinhamento institucional estar consolidado neste repositorio.
